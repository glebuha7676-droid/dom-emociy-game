# Дом эмоций

Развивающая игра о чувствах: семейный дом с интерактивными комнатами, тренировки по выражениям лиц и иллюстрированные истории.

**[Открыть игру](https://glebuha7676-droid.github.io/dom-emociy-game/)**

## В игре

- Одинаковая сцена 390 × 844 на телефоне и ПК, с масштабированием под экран.
- 5 комнат с 3D-иконками и портретами жильцов.
- 4 главы и 16 уровней, режимы «Угадай эмоцию» и «Найди эмоцию».
- 30 изображений эмоций и 6 нейтральных портретов семьи.
- 9 иллюстрированных историй с двумя вопросами, объяснениями и наклейками.
- Задание дня, звёзды и награды. Прогресс сохраняется в браузере.

## Истории по комнатам

| Комната | Истории |
|---|---|
| Гостиная | Башня из брусков |
| Кухня | Осторожно, горячее! |
| Детская | Новая кукла; Неожиданное «Бу!»; Смотри, мой рисунок! |
| Спальня 1 | Новое платье; Носки на место |
| Спальня 2 | История в книге; Тёплый подарок |

Картинки показываются целиком. Нажатие «Рассмотреть» открывает увеличенный просмотр. По одной истории в каждой комнате доступны сразу, остальные открываются по мере прохождения уровней.

## Локальная игра и редактор

Нужен Node.js 24 или новее. На Windows можно запустить **«Открыть редактор.cmd»**. Скрипт подготовит экспорт и запустит локальный сервер.

```sh
node tools/build-export.cjs
node serve.cjs
```

- Игра: http://127.0.0.1:8937/
- Редактор: http://127.0.0.1:8937/editor.html

Редактор позволяет перетаскивать элементы, менять размеры, текст, цвета и картинки. «Сохранить в игру» или Ctrl+S записывает оформление в project.js и обновляет автономный demo-one-file.html. Черновик сохраняется автоматически в браузере. Полная инструкция: [EDITOR.md](EDITOR.md).

На GitHub Pages опубликована сама игра. Запись редактора в файлы работает через локальный сервер.

## Публикация обновлений

При отправке изменений в ветку main GitHub Actions собирает _site и обновляет GitHub Pages. Локально проверить статическую сборку можно так:

```sh
node tools/build-site.cjs
```

После редактирования и нажатия «Сохранить в игру»:

```sh
git add .
git commit -m "Update game"
git push
```

## Основные файлы

- app.js — экраны, вопросы, прохождение и награды.
- game-data.js — персонажи, эмоции, комнаты и главы.
- story-data.js — девять семейных историй.
- portrait-data.js — доступные изображения эмоций.
- styles.css, mobile.css — оформление и мобильная сцена.
- editor.*, design-runtime.js, project-store.js — визуальный редактор и сохранение.
- tools/build-site.cjs — статическая сборка для Pages без сторонних библиотек.
- assets/ — используемые изображения и их описания.

Исходные предоставленные коллекции и промежуточные изображения не включены в репозиторий. Готовая графика, которую использует игра, включена полностью. Скрипты повторной подготовки изображений требуют исходных файлов; для запуска игры, редактора и сборки Pages они не нужны.
