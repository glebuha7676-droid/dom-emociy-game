# Круглые портреты семьи

Шесть отдельных портретов по эталонам из папки «ПЕРСОНАЖИ И ИХ ЭМОЦИИ».

| Персонаж | PNG | SVG |
|---|---|---|
| Бабушка | grandma.png | grandma.svg |
| Дедушка | grandpa.png | grandpa.svg |
| Мама | mother.png | mother.svg |
| Папа | father.png | father.svg |
| Брат | brother.png | brother.svg |
| Сестра | sister.png | sister.svg |

Все готовые PNG имеют размер **512 × 512**, прозрачный фон снаружи круга, общий светлый ободок и одинаковую геометрию. Выражения спокойно-дружелюбные: расслабленный взгляд, закрытый рот, без выраженной эмоциональной гримасы.

- `index.html` — просмотр набора, в том числе при размерах 48 и 80 пикселей.
- `family-preview.png` и `family-preview.svg` — все шесть портретов вместе.
- `masters/` — исходники генерации в полном разрешении.
- `prompts/` — точные промпты каждого персонажа.
- `manifest.json` — имена, размеры и пути файлов.

Лица созданы встроенным **image_gen** с эталонами персонажей. Единая SVG-рамка обеспечивает точный размер и круглую границу без изменения лиц; PNG экспортированы из этих рамок. Повторная сборка: `node tools/build-avatars.cjs` из папки проекта (нужен Sharp; готовые файлы не требуют библиотек).

Исходные эталоны и карточки не изменены. Это набор общих портретов семьи, не утверждённый список эмоций и не замена всех обучающих карточек.
