# 3D-иконки комнат

Пять отдельных PNG с прозрачным фоном сгенерированы встроенным инструментом `image_gen`. Для каждого сохранён точный промпт в файле `<id>.prompt.txt` рядом с изображением.

| Комната | Файл | Значок | Жильцы |
|---|---|---|---|
| Гостиная | living-v1.png | Бирюзовый диван | Общая комната |
| Кухня | kitchen-v1.png | Кастрюля с супом | Общая комната |
| Детская | kids-v1.png | Мишка с кубиком | Брат и сестра |
| Спальня 1 | parents-v1.png | Светлая кровать | Мама и папа |
| Спальня 2 | grandparents-v1.png | Деревянная кровать с лоскутным одеялом | Бабушка и дедушка |

`icons-preview.png` — обзор исходных иконок. В редакторе: «Графика → Дом → 3D-иконки комнат / Жильцы в кружках». Кружки используют готовые портреты из `assets/avatars`. Перенос кнопки комнаты переносит её жильцов вместе с ней. Все новые изображения включены в автономный HTML-экспорт.
