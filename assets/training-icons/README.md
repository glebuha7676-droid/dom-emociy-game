# Иконки тренировок

Четыре PNG с настоящим прозрачным фоном сгенерированы встроенным `image_gen`. Каждый исходный промпт сохранён рядом с изображением.

| Файл | Применение | Промпт |
|---|---|---|
| recognize-v1.png | «Угадай эмоцию», главная кнопка тренировок | recognize.prompt.txt |
| find-v1.png | «Найди эмоцию» | find.prompt.txt |
| medal-v1.png | «Путь эмоций» и продолжение текущей главы | medal.prompt.txt |
| daily-v1.png | Ежедневное задание | daily.prompt.txt |

Картинки можно заменить в редакторе: «Графика → Дом → Тренировки и прогресс». Замена применяется сразу во всех местах. Все четыре PNG включены в автономный экспорт.
